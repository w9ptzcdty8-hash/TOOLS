# DICE & COIN

スマートフォン向けWebツール。サイコロを振る／コインをトスするだけのシンプルなツールです。

## ファイル構成

```
index.html   画面構造
style.css    デザイン・レイアウト・アニメーション
script.js    ロジック（乱数生成・状態管理・localStorage）
```

## 機能

- DICE：個数1〜3、面数はD6 / D8 / D10 / D12から選択
- COIN：枚数1〜3
- 実行結果を最大10件まで履歴保存（localStorage）
- 設定値もlocalStorageに保存し、再訪問時に復元
- 外部ライブラリ不使用

## 公開方法

このフォルダの中身をそのままGitHub Pagesのリポジトリに配置すれば動作します。
`index.html` がエントリーポイントです。

## 注意

- 画面最下部の広告枠には、MRS WORKS共通テンプレートの広告コード（admax）をそのまま使用しています。
- D8 / D10 / D12 は正確な多面体の3Dメッシュではなく、回転・影・グラデーションによる疑似3D表現です。
